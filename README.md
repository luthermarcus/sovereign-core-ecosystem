# 🦊 Sovereign Core OS: Decentralized DePIN Settlement Hub & L1 Vault

Sovereign Core OS is an autonomous settlement hub bridging physical DePIN node bandwidth directly to Bitcoin self-custody.

## 💎 The 1% Optimized Treasury & Decentralized Security
To remain intensely competitive with major cross-chain routers while capturing robust growth capital, Sovereign Core enforces a streamlined **1% (100 bps) protocol fee**, structured to sustain the ecosystem:
- **Core Treasury:** Sustains maintenance of the L1/L2 bridge and core OPSEC.
- **DePIN Node Rewards:** Incentivizes physical bandwidth providers.
- **Developer Grant Pool:** Rewards contributors meeting open-source GitHub standards.

## 🛡️ 3-Pronged Bad-Actor & Threat Detection
The OS utilizes a distributed, multi-layer security model to neutralize malicious entities:
1. **L1 Security Filter:** Scans UTXO scripts to isolate dust attacks and tainted address clusters.
2. **L2 Intent Reputation Engine:** Monitors solver success rates in `/dev/shm`, instantly slashing and blacklisting misbehaving fillers.
3. **L3 DePIN Telemetry Audit:** Validates hardware yield data to prevent fake throughput spoofing.

## 🚀 Hybrid Operational Backend
- **Pruned Bitcoin Core (`bitcoind -prune=1000`):** Full L1 consensus validation and native fee splitting.
- **Electrum SPV Fallback:** Zero-downtime failover during hardware thermal limits.
