# 📜 Sovereign Core OS: Project Credits & Attributions

Sovereign Core OS synthesizes decades of open-source research and community development across three primary ecosystems:

## 1. Bitcointalk Community (Cryptographic Security)
* **Tier Nolan (2013):** Formalized the original Hash Time-Locked Contract (HTLC) cross-chain atomic swap framework (*Bitcointalk Topic #225640*).
* **Peter Todd:** Author of BIP 65 (`OP_CHECKLOCKTIMEVERIFY`), providing autonomous base-layer refund capabilities without trusted counterparties.
* **Sean Bowe & Daira Hopwood:** Authors of BIP 199 (BIP-HTLC standard), defining standardized Bitcoin script structures for atomic cross-chain exchange.

## 2. XDA Developers Community (Hardware & Terminal Environments)
* **Termux Development Team:** Headless Linux terminal infrastructure on Android mobile devices.
* **Android Linux Administration Hackers:** Mobile clipboard handling solutions, headless process daemonization, and SSH connection keepalive patterns.

## 3. Decentralized Physical Infrastructure Networks (DePIN)
* **Mysterium Network:** Distributed P2P VPN node infrastructure and bandwidth telemetry APIs.
* **EarnApp / Bright Data:** Distributed bandwidth proxy architecture.
* **TraffMonetizer, Honeygain, PacketStream, Pawns.app:** Residential network node telemetry.
